# KageTarget — Web Recon Toolkit

Inspect the active web page and user-selected HTTP(S) targets through a fast Chrome side-panel interface. Review page structure, links, resources, forms, response headers, CSP, conventional public files, URL components, and IPv4 subnet information without leaving the current page.

KageTarget has no account, backend, telemetry, analytics, or persistent scan history. Direct checks communicate only with the target selected by the user.
