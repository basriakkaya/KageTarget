# KageTarget — Web Recon Aracı

Aktif web sayfasını ve kullanıcı tarafından seçilen HTTP(S) hedeflerini hızlı Chrome yan panelinden inceleyin. Mevcut sayfadan ayrılmadan sayfa yapısını, bağlantıları, kaynakları, formları, HTTP başlıklarını, CSP'yi, herkese açık standart dosyaları, URL bileşenlerini ve IPv4 alt ağ bilgilerini görüntüleyin.

KageTarget hesap, backend, telemetry, analytics veya kalıcı tarama geçmişi kullanmaz. Doğrudan kontroller yalnızca kullanıcının seçtiği hedefle iletişim kurar.
